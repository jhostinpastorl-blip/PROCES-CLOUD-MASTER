# Notification RLS Matrix
1. Notificación global de Empresa A visible a miembros A.
2. Notificación dirigida a user A visible a user A.
3. Notificación dirigida a user A invisible a user B de la misma empresa.
4. Empresa B no ve ninguna notificación de A.
5. Usuario solo puede marcar como leída su notificación o global de su empresa.
