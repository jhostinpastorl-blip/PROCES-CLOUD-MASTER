# Onboarding matrix

1. New account starts at plan.
2. Leave after plan -> resume company.
3. Leave after company -> resume modules.
4. Leave after modules -> resume branch.
5. Complete -> app context.
6. User with existing completed onboarding does not restart.
7. Onboarding state from user A invisible to B.
8. Invalid plan rejected.
9. Module outside entitlement rejected.
10. Branch limit enforced even during onboarding.
