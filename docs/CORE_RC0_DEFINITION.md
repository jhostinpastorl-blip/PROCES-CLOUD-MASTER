# Definition of Done — Core RC0
Debe existir evidencia real, no solo código:
- npm ci PASS;
- typecheck PASS;
- build PASS;
- migraciones QA PASS;
- Auth PASS;
- onboarding PASS;
- tenant A/B PASS;
- RLS PASS;
- roles/permisos PASS;
- limits PASS;
- invitation PASS;
- platform admin PASS;
- audit PASS;
- responsive PASS;
- health/readiness PASS.

RC0 no significa producción: significa Core técnicamente validado en QA.
