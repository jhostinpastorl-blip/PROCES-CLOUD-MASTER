# Flujo comercial v0.21
Visitante -> landing -> Crear cuenta o Solicitar demo.
Crear cuenta -> registro -> plan inicial -> empresa -> módulos permitidos -> primera sucursal -> dashboard.
Solicitar demo -> lead -> contacto PROCESA -> propuesta -> empresa/plan.
Trial inicial técnico: 14 días. No implica aún cobro automático.
Precios definitivos y pasarela de pago quedan fuera hasta cerrar modelo comercial.
