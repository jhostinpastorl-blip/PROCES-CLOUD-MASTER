# Super Admin boundary
PROCESA Admin es panel de plataforma, no un bypass informal del tenant.
platform_admin identifica operadores autorizados de PROCESA CORP.
La UI vive fuera de /app en /procesa-admin.
Acciones globales críticas deben generar platform_audit_logs.
Ser platform_admin NO implica automáticamente membresía en todas las empresas.
Para soporte con acceso a datos de cliente se diseñará posteriormente un flujo explícito, temporal, auditable y con justificación.
