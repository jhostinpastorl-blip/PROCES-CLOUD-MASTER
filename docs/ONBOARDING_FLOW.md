# Onboarding premium
Login/registro -> detectar membresías -> crear empresa si no existe -> crear primera sucursal -> completar -> seleccionar contexto -> dashboard.
El onboarding no concede permisos desde frontend. Las funciones PostgreSQL crean owner/membership/rol admin de forma atómica.
Objetivo UX: que un nuevo cliente pueda pasar de cuenta creada a dashboard operativo en pocos pasos sin conocer la arquitectura interna.
