# Acciones manuales requeridas del propietario
No solicitar hasta llegar al punto correspondiente.

1. GitHub
- autorizar/conectar repositorio oficial.

2. Supabase
- crear o conectar proyecto QA.
- secretos se configuran en entorno, nunca se pegan en documentación.

3. Google Drive API
- autorizar credenciales server-side con alcance mínimo.

4. Cloudflare
- conectar cuenta/zona/dominio y deployment.

Cuando una etapa requiera intervención, dar pasos exactos y detener solo esa parte; continuar en paralelo con trabajo que no dependa de la conexión.
