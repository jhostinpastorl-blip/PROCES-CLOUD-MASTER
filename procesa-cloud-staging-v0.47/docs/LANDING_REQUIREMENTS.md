# Landing comercial — requisitos
La landing final debe responder sin ambigüedad:
Qué es PROCESA Cloud; para quién sirve; qué compra el cliente; cómo funciona; módulos; beneficios; seguridad; web/PWA; planes conceptuales; onboarding; soporte; preguntas frecuentes; solicitud de demo; login; contacto; términos y privacidad.
No publicar precios definitivos hasta aprobar modelo comercial.
Objetivo: convertir visitante -> demo/lead -> onboarding -> empresa activa.
