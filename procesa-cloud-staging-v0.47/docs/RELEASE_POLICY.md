# Política de Releases
v0.x = desarrollo previo a Core Beta.
RC0 = primera validación real del Core en QA.
Core Beta = utilizable por clientes piloto controlados.
1.0 = Core + primer módulo comercial estable según definición de producto.

Cada release debe registrar:
- versión;
- commit;
- migraciones;
- cambios;
- riesgos;
- pruebas;
- rollback;
- decisión GO/NO-GO.
