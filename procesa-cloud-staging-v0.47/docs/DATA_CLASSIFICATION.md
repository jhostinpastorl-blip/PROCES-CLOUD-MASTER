# Clasificación de datos
Public: landing, catálogo de módulos, información comercial.
Internal: configuración no sensible y métricas operativas agregadas.
Confidential: clientes, ventas, compras, inventario, documentos empresariales.
Restricted: credenciales, tokens, service roles, secretos, datos de autenticación.
Restricted nunca se guarda en Drive documental, código, logs o audit metadata. Solo secret manager/variables seguras del entorno.
